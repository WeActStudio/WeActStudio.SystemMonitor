## How to build
**STEP 1**  
run `env start.bat` and `env start 32.bat`  
**STEP 2**  
run `build_release.bat`
## How to run
If your system is 64-bit, please go to the `release` directory, find the folder named `64bit`, and then copy all the files inside it to the `release` directory. 32-bit and so on.
